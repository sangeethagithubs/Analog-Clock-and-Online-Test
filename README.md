# Analog-Clock & Online-Test using Applet and Swing-Java

# Analog Clock Using Applet
# Overview:

This project implements an Analog Clock using Java Applet. The clock displays the current time with hour, minute, and second hands, and updates in real-time.

# Features:
• Real-time clock display.

• Hour, minute, and second hands.

• Graphical representation of a traditional analog clock.

# Technologies Used:
• Java

• Java Applet

# Usage:

• Open the HTML file in a web browser to view the analog clock.

• The clock will display the current time and update every second.


# Online Test Using Swing Java

# Overview:

This project implements an Online Test application using Java Swing. It provides a graphical user interface (GUI) for taking tests with multiple-choice questions, and it keeps track of the score.

# Features:

• Multiple-choice questions with four options each

• Timer for each test

• Score calculation and display

• User-friendly GUI

# Technologies Used:

• Java

• Java Swing
